Linux Update Utility 1.2 is released!

This release of LUU will feel very familiar with some new theming and a complete rebuild;

No real features or bug fixes in this release, but here are the main notes:

- A much less boring GUI, less Qt template and more cultured
- Storage usage is a 10th of 1.1, from ~70MB installed down to ~7MB 
- All C++ code was removed in favor of Rust, the program consists only of Rust and Shellscript
- Stricter memory policies thanks to Rust and new design

I hope everyone enjoys the new theme, I am currently planning to work on the lack of complete fingerprint authentication support. For now it works in a buggy way which won’t show the authentication window but still authenticates, please just continue doing so and bear with me. 

Also please excuse the issue in downloading 1.1 which gave a 404 recently, I made a mistake in my back end. 

Installation instructions will be made available soon!

Enjoy,
