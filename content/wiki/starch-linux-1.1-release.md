Starch Linux 1.1 is released!

The new release of Starch Linux comes with many fixes and features;

Feature(s):

- Pre-configured on-screen keyboard
- An optional installer for touchscreen systems, prompted before installer is launched 
- Comes with Linux Update Utility 1.1

Fix(es):

- You can now change your shell with chsh
- System won’t lock during installation
- Live user has a password, it is “password”
- Bluetooth service enabled by default 
- BIOS installation creates a properly bootable partition setup

These fixes greatly improve ease of installation, make the OS compatible with more systems, improve ease of use and add more customization options. 

The addition of the on-screen keyboard in addition to Linux Update Utility’s newly added on-screen keyboard support allows for usage of a larger variety of hardware. People with touchscreen laptops are able to better use their hardware and Starch Linux is usable on handheld systems now. 

Hardware testing and real world testing for Starch Linux has expanded and is quite extensive, I personally run it on most of my computers and Tundra has tested it on multiple systems. It has been tested on modern systems like my Zen 4 desktop with a 9070XT and my R7 5700U 2-in-1 laptop. It’s been tested on low end systems like an 8th gen i3 laptop of mine and some borderline e-waste for BIOS boot testing. I even run it on my handheld, ROG Xbox Ally. Starch Linux 1.1 has proven its versatility to me, and I expect it to do the same for you.
