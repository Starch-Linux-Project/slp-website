Linux Update Utility 1.2.2 is released!

A new feature and fix combo is here!

I finally added proper fingerprint reader support. I was procrastinating doing this for a while but it turns out Codex only needed one very specific prompt with some good guidance to get it figured out. 

Now when it asks for your PIN it will detect any enrolled fingerprint readers and prompt for their use. If you want to type instead, it does not prevent you from doing so. 

Special thanks to Tundra, he did all of the testing for this update.
